# 0.3.0a3 — role matrix / balance pass

- Добавлен `tests/test_role_matrix.py`: 39 сценариев пересечения ролей и правил.
- Исправлено самолечение Хирурга: заблокированный Дивой/Костоломом self-heal больше не расходуется.
- Исправлена квота мафии в Classic/Virus: Взломщик, Тень и Мастер Алиби заменяют обычные слоты Торпед, а не добавляются поверх них.
- Проверено автоматически: стартовые раскладки 4–30 игроков не начинают игру уже в состоянии победы одной стороны.
- Подрывник после дневной казни теперь выбирает месть в следующую обычную NIGHT; отдельная зависающая мини-фаза удалена.
- Месть Подрывника восстанавливается после restart и разрешается утром вместе с ночными событиями.
- Исправлены победители: обычная командная победа начисляется выжившим победившей стороны; Живой Щит получает специальную посмертную победу только если реально спас будущего победителя.
- Победа Носителей теперь принадлежит всем живым заражённым, когда все выжившие заражены.
- Костолом получил более высокий приоритет блокировки, чем Ночная Дива: результат взаимной блокировки больше не зависит от порядка callback'ов.
- Добавлена проверка приватного канала Хирург ↔ Сестра Милосердия, наследования Дона, маскировок, Перевёртыша, Джокера, FriendlyFire и порогов Анархии.
- Финальный прогон: 33 core + 14 resilience + 39 role-matrix + SQLite + smoke + 1500 headless + 600 restart-fuzz.

# Mafia Optimisma v3 — ключевые изменения

- Перестроен игровой цикл на REGISTRATION → NIGHT → DISCUSSION → NOMINATION → VERDICT → FINISHED/NIGHT.
- Одноэтапное старое голосование заменено на номинацию + отдельный вердикт Да/Нет.
- Добавлены phase deadlines, phase_version, guarded timers и per-chat asyncio.Lock.
- Регистрационная карточка закрепляется, редактируется, затем disable/unpin/delete.
- Ошибки cleanup Telegram UI не блокируют state machine.
- Активная партия сохраняется в SQLite и восстанавливается после рестарта.
- Добавлена защита от полузапущенного snapshot на старте партии.
- Старые callbacks защищены session/day.
- Ночные/голосовательные PM-кнопки деактивируются по окончании фазы.
- Публичный список живых показывает стабильные номера и количества текущих ролей.
- Последнее слово ограничено текущим днём.
- Мёртвые/заглушённые/живые ночью фильтруются group guard'ом.
- Добавлены Mafia/Sakura team chat и уведомления о выборе лидера.
- Исправлен порядок блокировки/лечения/визитов.
- Разрешены множественные атаки одной цели в одну ночь.
- Перевёртыш поглощает соответствующий удар превращением.
- Добавлены наследования ролей и персональные уведомления.
- В Chaos исправлено продолжение партии при живом Потрошителе.
- Добавлены `/game`, `/stop`, `/notify`, `/gogame`, `/mystats` и обновлено Telegram command menu.
- Награды малых тестовых партий отключены по MIN_REWARD_PLAYERS.
- Groq/LLM отсутствует в критическом игровом пути.
