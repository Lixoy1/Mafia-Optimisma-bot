# Mafia Optimisma — правки логики теста

Изменено:

- Регистрация: закреп с одной кнопкой «➕ Присоединиться».
- Убраны лишние подсказки про /join из текста регистрации.
- Магазин заблокирован во время активной игры: ночь, обсуждение, голосование.
- /call теперь отправляет один пост с упоминаниями игроков, которые уже известны боту в этом чате.
- Под /call нет кнопки «Присоединиться», чтобы не путать созыв с регистрацией.
- Профиль больше не показывает кнопки магазина снизу.

Важно: Telegram Bot API не позволяет боту получить полный список всех участников группы. Поэтому /call может перечислять только тех, кто уже взаимодействовал с ботом или писал в чате после добавления бота.
