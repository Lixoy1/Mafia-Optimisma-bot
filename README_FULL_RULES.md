# Mafia Optimisma — full rules build

Эта сборка перепакована под тесты рабочей логики:

## Регистрация

- `/game1`, `/game2`, `/game3`, `/game4` запускают регистрацию соответствующего режима.
- Регистрация длится `REGISTRATION_SECONDS` секунд, по умолчанию 30.
- В закрепе только одна кнопка: `➕ Присоединиться`.
- Игрок добавляется только если открыл ЛС с ботом и бот может отправить ему сообщение.
- `/extend` продлевает регистрацию ещё на 30 секунд и перезапускает таймер.
- После таймера игра стартует автоматически.
- Если игроков меньше минимума режима, бот пишет, сколько есть и сколько нужно.

## Минимумы режимов

- `/game1` — 🏙 Городской оптимизм: минимум 4.
- `/game2` — 🌪 Весёлый хаос: минимум 3.
- `/game3` — 🧟 Эпидемия улыбок: минимум 13.
- `/game4` — 🌸 Война улыбчивых кланов: минимум 12.

## Классическая раскладка

На 4 игрока строго:

- 🤵🏻 Карлеоне
- 🩺 Хирург
- 🙂 Оптимист
- 🙂 Оптимист

Ищейка появляется только от 6 игроков.

## Важные правки логики

- Ищейка имеет действия `🔎 Проверить` и `🔫 Убить`, если режим разрешает выстрел.
- Уже проверенные Ищейкой игроки больше не показываются в списке проверки.
- Хирург может лечить себя только 1 раз за игру.
- Магазин недоступен во время активной игры.
- Под сообщениями ночи и голосования есть кнопка `🤖 Перейти в бота`.
- Голосование проходит в ЛС.
- `/call` отправляет один пост с тегами известных участников чата.
- `/unreg` выключает упоминание пользователя в созыве.
- `/reg` включает упоминание обратно.
- `/end_game` и `/end game` выводят игрока из игры с фразой про натиск мафии.

## Telegram ограничения

Telegram Bot API не отдаёт боту полный список участников группы. Поэтому `/call` может упоминать только тех, кого бот уже знает: писал в чате, нажимал кнопку регистрации, использовал команды или открыл ЛС.

## Проверка

Синтаксис проверен командой:

```bash
python -m compileall .
```

Для запуска на Railway нужны зависимости из `requirements.txt`.
