# Mafia Optimisma — групповые команды и админ-панель

После деплоя бот автоматически прописывает Telegram-меню команд для личных сообщений и групповых чатов.

## Команды группы

- `/game1` — запустить регистрацию в режиме **Городской оптимизм**
- `/game2` — запустить регистрацию в режиме **Весёлый хаос**
- `/game3` — запустить регистрацию в режиме **Эпидемия улыбок**
- `/game4` — запустить регистрацию в режиме **Война улыбчивых кланов**
- `/extend` — продлить/поднять регистрацию ещё на 30 секунд
- `/start` — запустить игру из регистрации
- `/join` — присоединиться к игре
- `/leave` — выйти из регистрации
- `/settings` — открыть админ-панель
- `/stats` — статистика игроков
- `/call` — созыв участников чата по @username
- `/unreg` — не упоминать меня в созыве
- `/reg` — снова упоминать меня в созыве
- `/players` — список игроков
- `/cancel_reg` — отменить регистрацию

## Важно про /call

Telegram Bot API не отдаёт боту полный список всех участников группы. Поэтому бот может созывать только тех, кто уже взаимодействовал с ботом в этом чате: писал команды, нажимал кнопку присоединения или попадал в регистрацию.

Если у пользователя нет username, бот покажет имя без настоящего тега. Чтобы тег работал как @username, участнику нужно иметь username в Telegram.

## Админ-панель

Команда `/settings` доступна только администраторам чата. В панели есть кнопки:

- выбор режима
- запуск игры
- продление регистрации
- созыв
- список игроков
- статистика
- отмена регистрации

## Если меню команд не появилось сразу

После деплоя Telegram может кешировать меню команд несколько минут. Проверь:

1. Бот перезапущен после обновления кода.
2. В Railway Logs есть строка `Mafia Optimisma started as @...`.
3. Бот добавлен в группу после обновления или группа перезапущена.
4. В BotFather отключён Privacy Mode: `/setprivacy` → Disable.
