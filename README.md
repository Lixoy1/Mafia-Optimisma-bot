# Mafia Optimisma — Telegram Bot

Красивый и полный бот для игры в Мафию с 26 ролями, 4 режимами, экономикой, предметами и командным чатом.

## Возможности
- 4 режима: Городской оптимизм, Весёлый хаос, Эпидемия улыбок, Война улыбчивых кланов
- 26 уникальных ролей с красивыми описаниями
- Регистрация 60 секунд с предупреждением и 3-2-1
- Ночные действия в ЛС с красивыми кнопками
- Командный чат мафии и якудзы ночью
- Голосование в ЛС
- Последнее слово
- Экономика, магазин, уровни, награды
- Полная очистка сообщений ночью
- Готов к деплою на Railway

## Установка

1. Клонируй репозиторий
2. Создай `.env` из `.env.example` и вставь токен бота
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запусти:
   ```bash
   python run.py
   ```

## Деплой на Railway

1. Создай новый проект на Railway
2. Подключи GitHub репозиторий
3. Добавь переменную окружения `BOT_TOKEN`
4. Deploy!

## Команды

### В группе:
- `/game1` — Городской оптимизм
- `/game2` — Весёлый хаос
- `/game3` — Эпидемия улыбок
- `/game4` — Война улыбчивых кланов
- `/extend` — Продлить регистрацию на 30 секунд
- `/call` — Созыв участников
- `/end_game` — Выйти из игры

### В ЛС:
- `/start` — Главное меню
- `/profile` — Профиль
- `/shop` — Магазин
