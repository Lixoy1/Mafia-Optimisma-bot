# Mafia Optimisma Bot

Рабочий прототип Telegram-бота для мафии на aiogram 3.x.

## Что уже есть

- Регистрация в группе через `/start_reg`, `/join` и кнопку «Присоединиться».
- Закреп регистрации, если у бота есть право закреплять сообщения.
- Режимы:
  - `/game1` — Городской оптимизм
  - `/game2` — Весёлый хаос
  - `/game3` — Эпидемия улыбок
  - `/game4` — Война улыбчивых кланов
- Раздача ролей в ЛС.
- Ночная фаза с действиями ролей.
- Голосование в ЛС.
- Последнее слово убитого.
- Командный чат мафии и Клана Сакуры через ЛС с ботом.
- Мини-магазин и профиль через SQLite.
- Предметы: оберег, документы, антивирус, парфюм, чёрная пуля, дневная защита.
- Автоудаление сообщений живых игроков ночью.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:

```env
BOT_TOKEN=токен_от_BotFather
```

Запуск:

```bash
python run.py
```

## Настройки BotFather

Желательно отключить Privacy Mode, чтобы бот мог удалять ночные сообщения в группе.
Также выдай боту права администратора на удаление сообщений и закрепление сообщений.

## Команды в группе

- `/start_reg` — начать регистрацию, режим по умолчанию.
- `/game1` — регистрация в режиме «Городской оптимизм».
- `/game2` — «Весёлый хаос».
- `/game3` — «Эпидемия улыбок».
- `/game4` — «Война улыбчивых кланов».
- `/join` — присоединиться.
- `/leave` — выйти до старта.
- `/players` — список игроков.
- `/call` — зазывала.
- `/start_game` — начать игру.
- `/cancel_reg` — отменить регистрацию.

## Команды в ЛС

- `/start`
- `/menu`
- `/profile`
- `/shop`
- `/roles`
- `/modes`

## Важно

Это цельный рабочий прототип. Он уже запускается и проводит игру, но для продакшена нужно добавить:

- хранение активных игр в Redis/PostgreSQL;
- защиту от нескольких параллельных таймеров после рестарта;
- админ-права только ведущим;
- больше балансировки ролей;
- тесты на все сложные комбинации ролей.
