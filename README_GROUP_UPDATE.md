# Обновление: групповая регистрация и админ-настройки

## Что изменено

- `/game1`, `/game2`, `/game3`, `/game4` доступны всем участникам чата.
- `/start` и `/start_game` доступны всем участникам чата.
- `/extend` доступен всем участникам чата.
- `/cancel_reg` доступен всем участникам чата.
- `/settings` доступен только администраторам чата.
- Inline-кнопки админ-панели также проверяют права администратора.
- При запуске регистрации бот отправляет и закрепляет сообщение с кнопкой `➕ Присоединиться`.
- Закреплённое сообщение автоматически обновляется после `/join`, нажатия кнопки `➕ Присоединиться` и `/leave`.
- В закрепе показывается список присоединившихся с нумерацией и @username, если он есть.

## Пример закрепа

```text
🎲 Начинается регистрация игры!
Режим: 🏙 Городской оптимизм

Нажимай кнопку «➕ Присоединиться» в закрепе или пиши /join.

👥 Присоединились:
1. @player_one
2. @player_two
3. Игрок без username

Всего игроков: 3
```

## Важно

Для закрепления сообщения бот должен быть администратором группы с правом `Pin messages`.
Для удаления ночных сообщений бот должен быть администратором группы с правом `Delete messages`.
